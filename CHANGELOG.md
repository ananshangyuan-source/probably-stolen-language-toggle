# Changelog

## 1.0.3 — 2026-10-10

Initial public release based on the player-verified recovery build.

- Q toggles the game's English and Simplified Chinese locales.
- Keeps ordinary text refresh and locale/font updates.
- Disables global text replacement and localization interception.
- Preserves native item rich text to avoid missing category labels.
- Adds portable automatic installation, enable/disable, and ownership-checked uninstall scripts.
- Generates bilingual tables from the user's own game; does not distribute game data.
- Adds Chinese/English documentation, source build instructions and issue templates.
- Plugin behavior verified on Demo build 25382790; release installer validated in isolation.

Known limitations: some open item panels need reopening; missing Chinese translations remain English; full-game compatibility is unverified.
